# Template flow audit

这个示例验证的是协作流程和模板注册一致性：

- 注册项必须回指同一份模板记录；
- 模板文件、来源笔记和记录中的摘要必须一致；
- UI 记录、活动切片、技术 profile 和模板来源必须属于同一个项目状态；
- `scaffold-kit` 默认先输出 dry-run，只有用户显式 `--apply` 才写文件；
- 用户决策和设计记录在 `.ddd/workflow-state.json` 和项目内证据文件中，便于多人共同查看；
- 记录、状态或模板发生漂移时，检查结果会报告冲突，不会自行替用户修正决策。

这个示例只使用项目内记录和 Git 历史作为协作审阅边界。
